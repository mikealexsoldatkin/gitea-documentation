### 4.3. Описание с помощью sequence-диаграммы
<!--
Sequence-диаграмма.
Удобна, если нужно сделать акцент на потоках данных
-->
```plantuml
@startuml
actor       User       as client
participant CRM         as crm
participant АБС         as abs

loop Пока не хватает документов
    client -> crm : [[frontendExample.md 1. Ввод данных анкеты]]
    
    activate crm
    crm -> crm : [[backendExample.md 2. Контроль целостности данных]]
    alt Не хватает документов
        crm -> client: 2.1. Уведомление о необходимости добавить доки
    end
end

crm -> abs : [[apiService.md 3. Отправка документов в АБС]]
deactivate crm
@enduml
```
