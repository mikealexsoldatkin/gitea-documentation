## ✳️ Структура
| **Атрибут**        | **Тип**                                                                                                                               | **Описание**       |
|--------------------|---------------------------------------------------------------------------------------------------------------------------------------|--------------------|
| `attribute_name`   | datatype, NOT NULL, FK ...                                                                                                            | Описание атрибута  |
| `attribute_enum`   | enum                                                                                                                                  | Описание атрибута  |
| `attribute_fk`     | int(11) NOT NULL, FK на [entity](/templates/Шаблоны%20страниц/Шаблон%20страницы%20-%20Архитектура%20системы%20-%20Модель%20данных.md) | Описание атрибута  |
| `virtualAttribute` | virtual + правила расчета                                                                                                             | Описание атрибута  |

<!--
    Пример:
    Атрибут: `id`
    Тип: int 11, NOT NULL, AUTO_INCREMENT
    Описание: Id, первичный ключ
-->
